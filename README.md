# Meadow Garden Services website

A responsive, static business website template designed for GitHub Pages.

## Files
- `index.html` — website sections and content
- `styles.css` — colours, layout and responsive design
- `script.js` — mobile menu, current year and enquiry form behaviour
- `assets/mgs-logo.jpeg` — supplied MGS logo
- `assets/mgs-banner.jpeg` — supplied MGS banner

## Before publishing
1. Open `script.js` and replace `ADD-YOUR-EMAIL-HERE` with the email address that should receive quotation requests. The form uses the visitor's email app (`mailto:`); it does not send enquiries through a server.
2. Review the service list and replace the placeholder About text with your own company details and service area.
3. Replace the gallery placeholders with real photos when you're ready.
4. Check that the phone number is correct.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new repository, for example `meadow-garden-services`.
2. Upload the contents of this folder to the repository root. Make sure `index.html` is at the root, not inside an extra nested folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish the site. The URL will be shown in Settings → Pages.

You can edit the HTML and CSS directly on GitHub later. GitHub Pages supports static sites like this one; a server-side form handler would require a separate service.
